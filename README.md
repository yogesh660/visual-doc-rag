# visual-doc-rag

Ask questions over annual reports full of tables and charts. Retrieval searches page
images directly instead of OCR text, and answers point to the exact page they came from.

Status: **planned**. The design, stack, milestones, evaluation and hosting plan are in
[docs/ROADMAP.md](docs/ROADMAP.md). Code lands milestone by milestone, starting with M0.
